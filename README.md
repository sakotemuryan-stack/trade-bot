# XAU_ICT_RSI_ATR / EURUSD_ICT_RSI_ATR: советники для MT5

Два файла с одинаковой логикой: `XAU_ICT_RSI_ATR.mq5` для XAUUSD (Magic 20261017) и `EURUSD_ICT_RSI_ATR.mq5` для EURUSD (Magic 20261018).

## Установка
1. В MT5: Файл → Открыть каталог данных → `MQL5/Experts`, скопировать туда `XAU_ICT_RSI_ATR.mq5`.
2. Открыть файл в MetaEditor и нажать «Компилировать» (F7).
3. Перетащить советника на график XAUUSD (таймфрейм графика не важен, советник сам берёт H1 и M5), включить «Алготрейдинг».
4. Сначала прогнать в Тестере стратегий (режим «Каждый тик на основе реальных тиков») и на демо-счёте.

## Логика

**Направление (H1)**
- RSI(14) на H1 (с v1.30): покупки, если RSI был 30 или ниже на одной из 3 последних закрытых свечей H1, продажи, если был 70 или выше. Уровня 50 больше нет.
- Опционально (выключено): ICT структура рынка на H1, сделка только в сторону последнего BOS (пробоя swing high / swing low).
- Опционально (выключено): premium/discount, покупки только в нижней половине диапазона последних 48 часов, продажи в верхней.

**Вход (M5)**, проверяется на закрытии каждой 5-минутной свечи, нужна свеча в сторону сделки и один из сигналов:
- Sweep (снятие ликвидности): свеча проколола минимум последних 20 свечей и закрылась выше него (для продаж зеркально по максимуму).
- FVG: цена вернулась в непробитый Fair Value Gap и закрылась выше его верхней границы.
- Order Block: цена вернулась в последнюю противоположную свечу перед импульсом и закрылась выше неё.

**ATR, SL, TP**
- Берутся 5 последних закрытых свечей H1 (текущая не считается), диапазон каждой = High − Low.
- Самая большая и самая маленькая отбрасываются, ATR = среднее трёх оставшихся.
- Stop Loss = 1.5 × ATR, Take Profit = 3 × ATR.

**Ограничения**
- Не больше одной открытой сделки (по символу и Magic number).
- Время сервера брокера: новые входы Пн–Чт 08:00–22:00, Пт 08:00–21:00. С v1.31 все позиции закрываются в пятницу в 23:00, в остальные дни сделка может держаться через ночь до TP или SL (InpCloseDaily = true вернёт закрытие каждый день).
- Лот считается так, чтобы на стопе терялся 1% баланса.

## Параметры
| Параметр | По умолчанию | Что делает |
|---|---|---|
| InpRiskPercent | 1.0 | Риск на сделку, % от баланса |
| InpFixedLot | 0 | Фиксированный лот вместо расчёта по риску |
| InpMaxRiskPercent | 5.0 | Если даже мин. лот 0.01 даёт больший риск, сделка пропускается |
| InpMaxSpreadPoints | 0 | Фильтр спреда (0 = выкл.) |
| InpATRTF | H1 | Таймфрейм свечей для ATR (с v1.20 по умолчанию H1) |
| InpATRBars | 5 | Сколько закрытых свечей для ATR |
| InpSLMult / InpTPMult | 1.5 / 3.0 | Множители SL и TP |
| InpUseTrailing | false | Трейлинг-стоп на расстоянии (ATR + SL)/2 = 1.25 × ATR, включается после прибыли на эту величину |
| InpUseBreakeven | true | Перевод в безубыток (добавлено в v1.10) |
| InpBETriggerATR / InpBEOffsetATR | 1.5 / 0.1 | Когда цена прошла 1.5×ATR (один стоп) в плюс, SL переносится на вход + 0.1×ATR |
| InpRSIPeriod, InpRSIBuyLevel, InpRSISellLevel | 14, 30, 70 | RSI на H1: Buy при ≤30, Sell при ≥70 |
| InpRSILookback | 3 | Сколько последних закрытых свечей H1 проверять на уровень RSI |
| InpUseHTFStructure | false | Дополнительно требовать BOS на H1 в сторону сделки |
| InpHTFSwingStrength | 3 | Свечей с каждой стороны для swing на H1 |
| InpUsePremiumDiscount | false | Фильтр premium/discount |
| InpUseSweep / InpUseFVG / InpUseOB | true | Какие сигналы входа на M5 разрешены |
| InpStartHour, InpEndHour, InpFridayEndHour, InpCloseHour | 8, 22, 21, 23 | Рабочие часы (время сервера) |
| InpCloseDaily | false | true = закрывать позиции в 23:00 каждый день, false = только в пятницу |
| InpMagic | 20261017 | Номер советника |

## Важно про счёт 100$
Минимальный лот на золоте 0.01 (1 унция): движение цены на 1$ = 1$ прибыли или убытка. При ATR на H1 около 10–20$ стоп будет 15–30$, то есть 15–30% от депозита 100$ на одну сделку, а не 1%. Советник в этом случае открывает 0.01 и пишет предупреждение в журнал; если риск больше InpMaxRiskPercent, сделка пропускается.
